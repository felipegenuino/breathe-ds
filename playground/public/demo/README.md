# Mídias de demo do hero (locais, fora do git)

O `PageVideoHero` do playground usa clipes de fundo que **não** são versionados
(ver `.gitignore`): são pesados e não devem carregar material real de paciente
no repositório do design system. Dropar aqui os arquivos abaixo para o demo rodar:

| Arquivo                   | Uso                        | Formato sugerido            |
|---------------------------|----------------------------|-----------------------------|
| `clip.mp4`                | Hero tipo **Loop**         | paisagem 16:9, ~1280×720, mudo, 8–12s |
| `clip-poster.jpg`         | Capa do Loop               | 16:9, 1 frame do clip       |
| `mariangela.mp4`          | Hero tipo **Player** (prévia) | retrato ou 16:9, mudo       |
| `mariangela-poster.jpg`   | Capa do Player             | 1 frame do clip             |

Clipes ambiente devem ser **genéricos** (sem pessoa real identificável) — preferir
stock livre ou geração por IA. O vídeo que toca no Player é o YouTube `h3a7DHFd6L4`.
